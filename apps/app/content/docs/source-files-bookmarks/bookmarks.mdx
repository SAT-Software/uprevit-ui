**Bookmarked Products** (`/bookmarked-products`) is separate from **source file folder bookmarks**. Here you organize **products** into personal folders for fast return to in-progress labeling work.

<DocsVideo videoKey="working-with-files.bookmarks" title="Bookmarks walkthrough" />

## Pages

| Page | Purpose |
|-------|---------|
| `/bookmarked-products` | Your bookmark folders, each with its product count. |
| A bookmark folder | Products saved inside one folder, with their version and status. |

## Folder actions

| Action | How |
|--------|-----|
| **Create a folder** | Click **Create Folder** on `/bookmarked-products`. |
| **Rename a folder** | Open the folder, click **Edit**, change the name, then click **Save Changes**. |
| **Delete a folder** | Open the folder, click **Delete**, type the folder name, then confirm. |

Folder names are required, can be up to 50 characters, and must be unique among your folders.

Deleting a folder only removes the folder and its bookmarks. The products themselves don't change.

## Adding products

Create a bookmark folder first. You can't create one while adding a product.

**From the products table**

1. Open the row menu on `/products`.
2. Choose **Add to Bookmarks**.
3. Choose a folder in **Select Bookmark Folder**, then confirm.

Once a product is bookmarked, the same menu item changes to **Remove Bookmark**.

**From inside a folder**

1. Open the folder.
2. Click **Add Products**.
3. Search for a product, select it, then click **Add Product**.

You add one product at a time. A product can be in several folders, but only once per folder.

## Removing products

Inside a folder, click the remove icon next to a product, then click **Remove**. You can also choose **Remove Bookmark** from the row menu on `/products`.

Removing a bookmark doesn't change the product.

## Permissions

Bookmark folders are personal. Every user manages their own folders, and nobody else can see them, including admins.

## Source file bookmarks vs product bookmarks

| Feature | Location | What is saved |
|---------|----------|----------------|
| **Source file folder bookmark** | `/source-files` | A folder in the source file tree |
| **Product bookmark** | `/bookmarked-products` | A product reference in a user folder |

See [Source Files](/docs/source-files-bookmarks/source-files) for the document library.
