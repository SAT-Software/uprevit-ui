A **product** in Uprevit is a labeling documentation record: metadata, seven structured tabs, versions, and outputs (PDF, Excel, reports). Products always belong to a **department** and **project** in your workspace hierarchy.

<DocsVideo videoKey="product.products-intro" title="Products tab introduction" />

## Product list

Open **Products** (`/products`) to see all products you can access. The table includes:

| Column | Meaning |
|--------|---------|
| **Product name** | Display name. |
| **PPN** | Product Plan Number (unique identifier). |
| **Project / Department** | Structural placement. |
| **Owner** | Product Owner accountable for the product. |
| **Status** | `Draft`, `Submitted`, `In Review`, `Released`, or `Obsolete`, with a link to the active workflow when In Review. |
| **Version** | Numeric version (e.g. v4), plus the released version when a newer one is being worked on (e.g. **Released v3**). |
| **Progress** | Tab completion percentage (0–7 tabs). |

Click a row to open **Product Information** for that product. Use the row menu for shortcuts without navigating away.

## Creating a product

Any signed-in workspace member can create a product.

1. Click **Create New Product**.
2. Complete the form:

| Field | Required | Notes |
|-------|----------|-------|
| **Product name** | Yes | |
| **PPN (Product Plan Number)** | Yes | Minimum **10** characters; must start with a letter or digit; use alphanumeric characters for the full identifier. |
| **Description** | Yes | Non-empty; max **220** characters. |
| **Department** | Yes | Searchable selector. |
| **Project** | Yes | Enabled after department is chosen; lists projects in that department only. |
| **Version** | Fixed | New products start at version **1** (displayed as 1.0). |
| **Status** | Fixed | New products start as **Draft**. |

3. Submit. Uprevit opens the product documentation workflow starting at **Product Information**.

## Editing basic product fields

From the products table menu, **Edit** updates **product name** and **description** only. PPN, department, project, version, and status are not changed from this dialog.

## Product documentation

After creating a product, open the seven documentation tabs from the product sidebar. See **[Product Overview](/docs/product-documentation/product-overview)** for what each tab covers, tab completion, header tools, and links to every detailed guide.

## Status and versions

| Status | Meaning |
|--------|---------|
| **Draft** | Editable; default for new products and new versions. |
| **Submitted** | Ready for an approval workflow; still editable. |
| **In Review** | Inside an active approval workflow; still editable. |
| **Released** | Approved and frozen; editing disabled on all tabs. |
| **Obsolete** | An earlier release replaced by a newer one. |

**Submit for approval** (product header) is available at 100% tab completion. An [approval workflow](/docs/review-outputs/approval-workflows) releases the version. To continue work after release, create a **New version** from the products table—see [Redlines and Versions](/docs/review-outputs/redlines-versions).

Archiving is separate from status: an archived product is hidden from active work, and its versions keep their status.

## Row actions

| Action | Who can use | Notes |
|--------|-------------|-------|
| Edit name/description | Product Owner, Contributors, or admins | Draft, Submitted, or In Review versions only. |
| New version | Product Owner, Contributors, or admins | Only when the latest version is **Released** and the product is not archived. |
| Share | All users | Copies product URL. |
| Bookmark | All users | Adds to bookmark folders; see [Bookmarks](/docs/source-files-bookmarks/bookmarks). |
| Export PDF | All users | Queues async job; see [Exports](/docs/review-outputs/exports). |
| Archive | **Admin only** | Moves the product to Archive. |

<Callout type="warn" title="Admin only">
**Archive** on the products table moves the product to Archive and is restricted to admins.
</Callout>

## Archiving and restoring products

Admins archive products from the table menu. Restore archived products from **Archive → Products** (`/archive`). Restored products keep the status each version had.
