**Label Components** catalogs each physical labeling element—labels, tags, stickers, packaging panels, and similar items—with optional images and structured attributes.

<DocsVideo videoKey="product.label-components" title="Label Components tab walkthrough" cropPadding />

## Component fields

| Field | Required | Notes |
|-------|----------|-------|
| **Component Number** | Yes | Identifier for the component within the product. |
| **Component Type** | Yes | Pre-printed, Blank, or N/A. |
| **Description** | No | |
| **Dimensions** | No | Free text (e.g. size notation). |
| **Print Direction** | No | Free text describing the printing direction. Also included in PDF exports. |
| **Label Type** | No | Multiple tags (e.g. primary, secondary). Press Enter after each one. |
| **Component Image** | No | PNG, JPEG, JPG, GIF, or WebP. |

## Adding and editing

1. Click **Add Component**.
2. Fill required fields and optionally upload an image.
3. Click **Add Component**. The component appears in the table. Rows with an image can be expanded to preview it.
4. To change or remove a component, open its **More actions** menu (**⋮**) and choose **Edit** or **Delete**.

The table is sorted by component number. Click a column header to sort by another column, use the filter control to filter by any field, and use the column menu to show or hide columns. The table shows 10 components per page.

Draft, Submitted, and In Review versions can be edited. **Released** and **Obsolete** versions disable add, edit, and delete. Only the Product Owner, Contributors, and admins can edit.

## Tab completion

Hover the progress in the product header and click **Mark Complete** when all components for this version are documented.

## Version comparison (redline)

Compare mode highlights changed cells in the table and shows OLD/NEW image pairs. Removed components stay visible with deletion styling; actions on removed rows are disabled.

Full steps for compare mode: **[Redlines and Versions](/docs/review-outputs/redlines-versions)**.
