**Product Specifications** (`/products/{productId}/product-specifications`) is a workbook-style grid for structured specification data: column headers, column types (constant, variable, N/A), and cell values.

<DocsVideo videoKey="product.product-specifications" title="Product Specifications tab walkthrough" />

## Workbook structure

| Part | Description |
|------|-------------|
| **Headers** | Column names you define. |
| **Column types** | Per column: `constant`, `variable`, or `na`. |
| **Cells** | Values at row/column intersections. |
| **Column order / widths / formats** | Layout and display preferences. |

There is no per-cell required validation—the grid is free-form for your specification template.

## Editing

- Click cells to edit values inline.
- Add or remove **rows** and **columns** from toolbar actions.
- Use **Find & Replace** (Ctrl+R) for bulk text updates.
- **Undo / Redo** for recent grid changes.

### Saving

- **Save** — writes the workbook to the server (`add_product_data` on the product-specifications tab). Click **Save** after editing; the toolbar shows **Unsaved changes** until the server confirms.
- Changes are **not** saved automatically. If you navigate to another tab or page without saving, Uprevit shows an **Unsaved Changes** dialog so you can save, discard, or stay on the page.
- Closing or refreshing the browser tab with unsaved edits triggers the browser’s leave warning.

### Released products

When status is **Released** or **Obsolete**, the grid is **read-only**: no edits or save.

## Toolbar extras

- **Filters** — narrow visible rows.
- **Page info** — keyboard shortcuts and grid help.
- **Export** — download the current grid immediately as an Excel workbook (local export, not the async jobs queue).

For workspace-wide PDF/Excel jobs, see [Exports](/docs/review-outputs/exports).

## Importing Excel workbooks

Use **Import** to load an Excel workbook. Import replaces the current grid; if it already contains data, confirm the replacement first. Click **Save** after importing to keep the result.

- **One sheet:** the first row becomes column headers. An optional second row containing only `constant`, `variable`, `na`, or `blank` values becomes column types. The remaining rows become cell values.
- **Multiple sheets:** all sheets are stacked vertically in workbook order inside the existing single grid. Each non-empty sheet starts with its name, followed by its original rows, including headers and any type row. A blank row separates sheets. Headers and type rows stay as ordinary cells because different sheets can have different layouts; global column headers and types start blank.
- Empty sheets are skipped. Import keeps cell values, including cached formula results, but does not preserve formulas, images, merged cells, or Excel formatting.
- The file must be at most **5 MB**, with at most **150 columns** and **5,000 combined rows**, including sheet names and separators. Files exceeding these limits are rejected without replacing the current grid.
- Export downloads the stacked result as **one Excel sheet**. It does not recreate the original sheet tabs.

These import rules also apply to [Operational Parameters](/docs/product-documentation/operational-parameters). Separate editable sheet tabs are planned for a future version.

## Tab completion

Mark **Product Specifications** complete in the header when the workbook is finalized for this version.

## Version comparison (redline)

In compare mode the grid shows the **current** version’s data with differences against the selected older version:

- **Highlight** mode — changed cells emphasized.
- **Inline** mode — strikethrough old values with new values beside them.

Header and column-type changes are diffed as well.

This tab participates in redline display but does not define the workflow—see **[Redlines and Versions](/docs/review-outputs/redlines-versions)** for Compare Versions, clearing comparison, and switching tabs while comparing.

## Legacy spec archive route

A separate read-only route (`/products/{productId}/product-spec-archive`) exists for historical Univer-based viewers and side-by-side spreadsheet comparison. Day-to-day editing uses this **Product Specifications** tab.
