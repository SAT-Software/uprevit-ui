title: System Status
description: Check whether Uprevit is running normally before you report a problem.
---

The **System Status** page shows whether Uprevit is available, and lists current incidents and planned maintenance. Check it first when the app is slow, a page won't load, or an action keeps failing.

## Open the status page

Click **System Status** in the **Help** section of the app sidebar. The status page opens in a new browser tab.

The status page is public and doesn't need you to sign in. You can bookmark it to check Uprevit even when you can't open the app.

If you don't see **System Status** in the sidebar, your deployment has no status page set up.

## What to do during an issue

1. Open **System Status**.
2. If an incident is listed, wait for the update shown there. You don't need to contact support about it.
3. If no incident is listed and the problem continues, [contact support](/docs/support). Describe what happened and add a screenshot if you can.
